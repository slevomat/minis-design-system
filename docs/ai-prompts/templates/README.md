## What are Templates?

Templates are complete page structures:
- Full HTML documents
- Multiple sections combined
- Ready to customize
- Production-ready starting points

## Using Templates

Each template page includes:
- **Full code** - Complete HTML
- **Structure diagram** - Page layout
- **Customization points** - What to change
- **AI prompts** - For variations
- **Content guidelines** - Copy recommendations
