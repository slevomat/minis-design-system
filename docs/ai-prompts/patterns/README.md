Composable UI patterns combining multiple components.

- More patterns coming soon...

## What are Patterns?

Patterns are reusable combinations of components that solve common UI challenges:
- Not full pages (those are templates)
- Not single components (those are in components/)
- Composable and flexible
- Include styling and structure

## Using Patterns

Each pattern page includes:
- **Visual structure** - ASCII diagram
- **Code template** - Copy-paste ready
- **Variants** - Different configurations
- **Responsive behavior** - Mobile/desktop
- **AI prompts** - For code generation
